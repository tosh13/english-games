# english-games

作成日：2026-11-12

ブラウザで開くだけで遊べる、英語学習用のゲーム。各ゲームは HTML 1枚で完結し、GitHub Pages で公開している。

- [English Crossword](crossword/index.html)：13×13 の英語クロスワード。共通テスト程度の語彙を6つのお題に分けて持ち、開くたびに盤を自動で組む。ヒントは英語の説明と日本語の意味の両方。答え合わせ・1文字見る・全部の答えを見るがある。公開先は <https://tosh13.github.io/english-games/crossword/>

## 単語を足す・お題を増やす

`crossword/index.html` の `TOPICS` に `[答え（大文字の英字のみ・13文字以内）, 英語のヒント, 日本語の意味]` を足す。1つのお題に20語以上あると、毎回12語前後の盤が組める。

## 同じ問題を開き直す

URL の `#t=<お題>&s=<番号>` が問題を決める。同じ URL を開けば同じ盤になり、途中まで解いた内容はそのブラウザに残る。
